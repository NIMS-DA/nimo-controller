We will run a coffee-ring experiment that maps a phase diagram of the dried droplet. Perform exactly 20 experimental cycles. In each of the first 5 cycles, choose the next candidate using the selection tool with the RE (random exploration) method. In each of the remaining 15 cycles, choose the next candidate using the selection tool with the PDC (phase diagram construction) method. In every one of the 20 cycles, after the candidate is proposed, run the following steps in this order: load a clean plate, prepare the sample with the proposed pva and dtab concentrations, and heat the plate. Then evaluate the get_image tool and register the returned value as the objective via an update. Finally, still inside the same cycle, place the plate back in the rack. After all 20 cycles are finished, plot the phase diagram.
