We will run a milk-drop experiment that maps a phase diagram. Perform exactly 30 experimental cycles. In each of the first 10 cycles, choose the next candidate using the selection tool with the RE (random exploration) method. In each of the remaining 20 cycles, choose the next candidate using the selection tool with the PDC (phase diagram construction) method. In every one of the 30 cycles, after the candidate is proposed, run the following steps in this order: set the volume to the proposed volume, aspirate the milk, set the height to the proposed height, and drop the milk. Then evaluate the analyze_result tool and register the returned value as the objective via an update. After all 30 cycles are finished, plot the phase diagram.
